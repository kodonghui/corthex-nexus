# SCR-142 프로젝트 첫 화면과 사용자 할 일

[English](SCR-142.md)

주소: `/`. `?view=todo`는 전체 할 일을 엽니다. 흐름: FL-001, FL-002, FL-003, FL-006, FL-007, FL-008, FL-011.

목적: 아침 보고에서 최대 5개 할 일을 바로 처리하고 전체 할 일이나 모든 프로젝트를 엽니다(SPEC-042).

## 항목 240: 아침 보고

첫 화면에 사용자 할 일 카드를 최대 5개 표시합니다. 확정 대기 그림에 걸린 질문·제안을 먼저 놓고 각 우선순위 안에서는 오래된 순으로 놓습니다. 전체 할 일은 오래된 순의 받은편지함입니다. 머리줄 링크에서 모든 프로젝트를 엽니다. 카드에서 답글과 제안 결정을 할 수 있는 정보와 행동을 제공하고, 확정은 그림 내용 이름과 변경 수를 미리 보여 주고 전체 그림 링크를 제공한 뒤 한 번 더 묻습니다. 답글과 제안 결정은 SCR-145에서 정한 10초 되돌리기를 제공합니다. 기존 백업 경고, 읽기 실패와 이전 정보 표시는 유지합니다.

질문 글이나 제안 요약이 없는 카드는 내용을 모른 채 결정하는 버튼을 내놓지 않고, 그림에서 전체 내용을 확인하는 링크를 제공합니다.

첫 아침 카드의 프로젝트는 선택한 시간선 목업의 쉬운 이름으로 13단계 진행 줄을 보여 줍니다. 프로젝트는 있지만 아침 카드가 없으면 첫 프로젝트의 진행을 보여 줍니다. 전체 할 일은 50개씩 보여 주며 같은 순서로 다음 항목을 여는 버튼을 제공합니다.

완성하지 않은 카드 답변은 현재 할 일 항목에 연결해 이 탭의 세션 저장소에 남깁니다. 화면을 다시 그리면 초안을 복원하고, 나중에 온 질문은 빈 칸으로 시작합니다.

아침 보고는 인사, 할 일 수, 답변과 제안을 10초 안에 되돌릴 수 있다는 안내로 시작합니다. 카드 머리에는 프로젝트 이름과 쉬운 단계 이름을 먼저 보여 주고, 다른 기술 용어는 보조 정보로 표시합니다. 질문 선택지는 바로 누를 수 있으며 “직접 쓰기”를 열면 입력 칸이 나타납니다. 저장된 초안은 다시 그린 화면에서도 보입니다. 그림 링크는 답변·결정 버튼보다 보조로 표시합니다. 확정은 그림 내용 미리보기와 별도 확인을 유지하고, 그림을 맞다고 표시 → AI 기록 → 모든 그림과 표의 기록 뒤 단계 통과를 순서대로 설명합니다.

13단계 줄은 열려 있거나 다시 확인할 현재 단계, 그런 단계가 없으면 다음 시작 전 단계를 구별하고, 모두 통과했다면 현재 단계를 만들지 않습니다. 상태는 색뿐 아니라 접근 가능한 이름과 표시로 제공하고 “시작 전”을 반복하지 않으며 이름은 칸 안에 들어갑니다. 진행 정보 읽기에 실패하면 다시 확인을 제공하고 이전 정보는 표시합니다. 좁은 화면은 처음에 현재 단계를 보여 주고, 사용자가 직접 옮긴 위치는 화면을 다시 그려도 유지합니다. 넓은 화면의 옆 열에는 조회 시점의 어제 시작부터 도착한 프로젝트 자료를 API-262의 프로젝트별 최신 `pushed_at`만으로 보여 주고, 프로젝트별 통과 단계 수는 `stages_passed`에서 가져옵니다. AI 활동 전체는 볼 수 없다고 밝히는 최신 전송 요약이며 날짜가 없거나 알 수 없는 내용은 만들지 않습니다. 좁은 화면에서는 옆 열이 카드 뒤에 같은 순서로 놓입니다. 사용자님이 2026-11-28에 요청한 표시 정정이며 순서, 결정 API, 확정 차단과 10초 되돌리기는 기존 승인대로입니다.
