# SCR-142 사용자 할 일

[English](SCR-142.md)

주소: `/`. 흐름: FL-001, FL-002, FL-003, FL-006, FL-007, FL-008, FL-011.

목적: 사용자가 모든 프로젝트에서 자기를 기다리는 일을 최신순으로 보고 엽니다(SPEC-042).

## 데이터

| 데이터 | 출처 |
| --- | --- |
| 헤더: "내 차례 N", 할 일 수 | API-263 |
| 헤더: 프로젝트 메뉴 | API-262 |
| 프로젝트별 할 일: 확정할 그림, 답할 AI 제안, 에이전트 질문, 새 그림으로 풀린 확정 | API-263 |
| 하루 백업 실패 경고 | API-263 |
| 할 일이 없을 때의 프로젝트 목록 | API-262 |

## 동작

| 동작 | 오퍼레이션 | 결과 | 실패 |
| --- | --- | --- | --- |
| 항목 열기 | - | 그 그림·요소·스레드에서 단계 작업대가 열림(SCR-145, ?d= 또는 ?thread=) | 그새 답했거나 사라짐 → 작업대가 없다고 보여 줌 |
| 프로젝트 열기(빈 상태) | - | 프로젝트 화면이 열림(SCR-144) | 그새 지워짐 → SCR-144가 없다고 보여 주고 프로젝트 목록 링크 |

## 상태

| 상태 | 사용자가 보고 할 수 있는 것 | 응답 |
| --- | --- | --- |
| SCR-142#normal | 프로젝트별로 묶은 항목을 최신순으로 보여 줍니다. 항목마다 종류 태그, 단계, 그림 이름, 한 줄 글, 시각이 있습니다. 백업이 실패하면 성공할 때까지 맨 위에 경고가 있습니다. 목업에서: 헤더의 "내 차례 N"이 이 목록의 수입니다. 휴대폰에서: 같은 목록을 한 칸으로. | API-262#200, API-263#200 |
| SCR-142#loading | 목록 자리에 회색 줄(프로젝트마다 두 줄). 버튼 없음. | - |
| SCR-142#empty | "기다리는 일이 없어요"와 프로젝트 목록(SPEC-042). 프로젝트가 아직 없으면 "에이전트가 처음 보내면 여기에 나와요"와 SCR-143의 에이전트 자격 링크. | API-262#200, API-263#200 |
| SCR-142#error | "문제가 생겼어요. 다시 해 보세요."와 다시 시도, 추적 ID. 헤더는 그대로 동작. | API-262#default, API-263#default |
| SCR-142#permission | 401: 게이트로 갔다가 여기로. 403: "이 NEXUS의 소유자만 열 수 있어요"만. | API-262#401, API-262#403, API-263#401, API-263#403 |
| SCR-142#stale | 제목 옆에 "10:42에 읽음". 탭이 다시 보이면 목록을 다시 읽음. 그새 답한 항목은 SCR-145에서 바뀐 상태로 열림. | - |

## 경우의 종류

| 종류 | 화면이 보여 주는 것 |
| --- | --- |
| Access | permission 상태 |
| Target | 그새 사라진 항목은 SCR-145에서 "더 이상 없어요"로 열림 |
| Outside services | 백업 실패는 맨 위 경고, 목록은 그대로 동작 |
| Empty and streamed answers | empty 상태. 스트리밍 응답은 없음 |
| Screen states | 모든 상태를 360·1440픽셀로 |
