# SCR-142 프로젝트 첫 화면과 사용자 할 일

[English](SCR-142.md)

주소: `/`. `?view=todo`는 전체 할 일을 엽니다. 흐름: FL-001, FL-002, FL-003, FL-006, FL-007, FL-008, FL-011.

목적: 아침 보고에서 최대 5개 할 일을 바로 처리하고 전체 할 일이나 모든 프로젝트를 엽니다(SPEC-042).

## 항목 240: 아침 보고

첫 화면에 사용자 할 일 카드를 최대 5개 표시합니다. 확정 대기 그림에 걸린 질문·제안을 먼저 놓고 각 우선순위 안에서는 오래된 순으로 놓습니다. 전체 할 일은 오래된 순의 받은편지함입니다. 머리줄 링크에서 모든 프로젝트를 엽니다. 카드에서 답글과 제안 결정을 할 수 있는 정보와 행동을 제공하고, 확정은 그림 내용 이름과 변경 수를 미리 보여 주고 전체 그림 링크를 제공한 뒤 한 번 더 묻습니다. 답글과 제안 결정은 SCR-145에서 정한 10초 되돌리기를 제공합니다. 기존 백업 경고, 읽기 실패와 이전 정보 표시는 유지합니다.

질문 글이나 제안 요약이 없는 카드는 내용을 모른 채 결정하는 버튼을 내놓지 않고, 그림에서 전체 내용을 확인하는 링크를 제공합니다.

첫 아침 카드의 프로젝트는 선택한 시간선 목업의 쉬운 이름으로 13단계 진행 줄을 보여 줍니다. 프로젝트는 있지만 아침 카드가 없으면 첫 프로젝트의 진행을 보여 줍니다. 전체 할 일은 50개씩 보여 주며 같은 순서로 다음 항목을 여는 버튼을 제공합니다.

완성하지 않은 카드 답변과 그 답변을 구분하는 질문 글은 이 탭의 세션 저장소에 남아, 화면을 다시 그릴 때 해당 질문의 초안만 복원합니다.
