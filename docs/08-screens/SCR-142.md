# SCR-142 Owner home and to-do

[한국어](SCR-142.ko.md)

Path: `/`; `?view=todo` opens the full to-do. Flows: FL-001, FL-002, FL-003, FL-006, FL-007, FL-008, FL-011.

Purpose: The owner sees projects and their pending counts first, and can open the full to-do (SPEC-042).

## Data

| Data | Source |
| --- | --- |
| Header: "My turn N", the number of to-do entries | API-263 |
| Header: the project menu | API-262 |
| To-do entries per project: diagrams to confirm, AI proposals to answer, agent questions, confirmations lifted by a new drawing | API-263 |
| The warning of a failed daily backup | API-263 |
| The projects, when there is nothing to do | API-262 |

## Actions

| Action | Operation | Result | Failure |
| --- | --- | --- | --- |
| Open an entry | - | The stage workbench opens at the diagram, element or thread (SCR-145 with ?d= or ?thread=) | The entry was answered or removed meanwhile → the workbench shows that it is gone |
| Open a project (empty state) | - | The project page opens (SCR-144) | The project was deleted meanwhile → SCR-144 shows it is gone with a link to the projects |

## States

| State | What the owner sees and can do | From responses |
| --- | --- | --- |
| SCR-142#normal | The default home lists projects with question and review counts, opens each project, and links directly to its newest question when present. An unavailable count is not shown as zero, and a capped to-do is labelled as a minimum. The full to-do opens at ?view=todo. Entries grouped by project, newest first; each shows its kind as a tag (confirm, proposal, question), the stage, the diagram's name, for a confirmation why it waits (never confirmed, lifted by a new document, cancelled), and how long it has waited. A question names its diagram and says to open it and reply in the thread (SPEC-054). A failed backup shows as a warning on top until a backup succeeds. From the mockup: the header's "My turn N" is this list's count. On a phone: the same list in one column. | API-262#200, API-263#200 |
| SCR-142#loading | Grey rows in the list's places, two per project group; no buttons. | - |
| SCR-142#empty | "Nothing waits for you" and the project list (SPEC-042). With no project yet: "A project appears here when an agent sends it for the first time", and a link to the agent credentials on SCR-143. | API-262#200, API-263#200 |
| SCR-142#error | "Something went wrong. Try again." with a retry and the request's traceId; the header still works. | API-262#default, API-263#default |
| SCR-142#permission | 401: the gate, then back here. 403: only "Only the owner of this NEXUS can open it". | API-262#401, API-262#403, API-263#401, API-263#403 |
| SCR-142#stale | "Read at 10:42" beside the title; the list reads again when the tab comes back into view. A failed refresh keeps the previous counts or list marked as old with a retry; an initial failure never displays zero. An entry answered meanwhile opens to its new state on SCR-145. | - |

## Kinds of cases

| Kind | What the screen shows |
| --- | --- |
| Access | permission state |
| Target | an entry gone meanwhile opens to "no longer in NEXUS" on SCR-145 |
| Outside services | a failed backup is a warning on top; the list still works |
| Empty and streamed answers | empty state; there are no streamed answers |
| Screen states | every state at 360 and 1440 pixels |
