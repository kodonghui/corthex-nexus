## Item 240: morning report

The home shows up to five owner to-do cards. Questions and proposals on diagrams awaiting confirmation come first; within each priority group the oldest comes first. The full to-do is an inbox in oldest-first order. A header link opens all projects. Cards offer the actions and information needed to reply or decide; confirmation previews named diagram contents and change count, links to the full picture, and asks again. A reply or proposal decision waits ten seconds with Undo, as specified in SCR-145. The existing backup warning, unavailable and stale states remain visible.

A card that lacks question text or a proposal summary does not offer a decision without context; it links to the diagram to inspect the full content instead.

The first morning card's project has a 13-step progress line using the plain-language names in the selected timeline mockup. When there are projects but no morning cards, it shows the first project's progress instead. The complete inbox shows entries in batches of 50, with a button to show the next entries in the same order.

An unfinished card reply stays in this tab's session storage under the current to-do entry, so a redraw restores the draft and a later question starts empty.
