# SCR-146 Changes since the last confirmation

[한국어](SCR-146.ko.md)

Path: `/p/{project}/{part}/{stage}/changes`, with the optional query `?d={diagram}`. Flows: FL-002, FL-004, FL-006.

Purpose: The owner sees every element added, removed or changed since the last confirmed version, cancels direct edits that wait for reflection, and confirms (SPEC-023, SPEC-029, SPEC-034).

## Data

| Data | Source |
| --- | --- |
| Header: "My turn N", the number of to-do entries | API-263 |
| Header: the project menu | API-262 |
| Changes since the last confirmed version: the elements added, removed and changed, named from the current diagram, and the confirmed commit; the direct edits waiting for reflection | API-265 |
| The project's repository, for the link to the confirmed version | API-264 |

## Actions

| Action | Operation | Result | Failure |
| --- | --- | --- | --- |
| Cancel a direct edit | API-273 | It leaves the list and the diagram shows the element as before | Already reflected → stale |
| Confirm the diagram | API-275 | The confirmed state, with the way back to the diagram | Waiting changes → the waiting state; the document changed → stale; not drawn → the not-drawn state |
| Back to the diagram | - | SCR-145 opens | None |

## States

| State | What the owner sees and can do | From responses |
| --- | --- | --- |
| SCR-146#normal | One row per changed element: a tag (added, removed, changed) and its name from the current diagram, or its key when it was removed; above the list, a link to the document at the confirmed version in the repository, as the "before" (SPEC-034); at the end, when confirmation is available, an explanation to answer questions, review changes and request AI recording before the confirm button. For diagrams other than mockups, explain that remaining AI proposals are not included in the confirmation. From the mockup: the work panel's "changed since the confirmation" list in full. For a removed diagram only the changes show, with no confirm button (SPEC-027). On a phone: Confirm is offered after one more question when available; Cancel edit remains on a PC. | API-262#200, API-263#200, API-264#200, API-265#200, API-273#200 |
| SCR-146#loading | Grey rows in the list's places; the confirm button is off. | - |
| SCR-146#empty | Never confirmed: "Not confirmed yet, so there is nothing to compare with." Nothing changed: "Nothing changed since the confirmation." (SPEC-034) | API-265#200 |
| SCR-146#error | 404: after a confirmation, the diagram is read again first, and a removed one still listed shows only its changes, with no confirm button (SPEC-027); otherwise the diagram or the change is gone, with a link to the project or a reload; others: a message and a retry. | API-262#default, API-263#default, API-264#404, API-264#default, API-265#404, API-265#default, API-273#400, API-273#404, API-273#409 (request-key-reused), API-273#413, API-273#415, API-273#default, API-275#400, API-275#404, API-275#409 (request-key-reused), API-275#413, API-275#415, API-275#default |
| SCR-146#permission | 401: the gate, then back here. 403: only the not-owner message; cross-site: a reload. | API-262#401, API-262#403, API-263#401, API-263#403, API-264#401, API-264#403, API-265#401, API-265#403, API-273#401, API-273#403, API-275#401, API-275#403 |
| SCR-146#stale | "The document changed. Look at the new version." with a reload. | API-273#409 (change-set-state), API-275#409 (document-changed) |
| SCR-146#waiting | Every change set waiting for reflection: they come first, each direct edit with Cancel edit (on a phone, without it) and each accepted AI proposal without it, and the confirm button is off with "Reflect or cancel the waiting changes first". | API-275#409 (waiting-reflection) |
| SCR-146#not-drawn | The document does not draw: the confirm button is off with "Fix the document so that it draws, then confirm." and a link to the diagram, where the failure shows. The state can be reached on a PC or phone. | API-275#409 (not-drawn) |
| SCR-146#confirmed | "This diagram is confirmed. The stage passes when every diagram and table in the stage is recorded." over an empty list, with the way back to the diagram. The state can be reached on a PC or phone. | API-275#201, API-275#200 |

## Kinds of cases

| Kind | What the screen shows |
| --- | --- |
| Access | permission state |
| Target | 404: the diagram or the change is gone |
| Concurrency | the document changed → stale |
| Repeats | Cancel edit and Confirm are off while they run |
| Screen states | every state at 360 and 1440 pixels |
