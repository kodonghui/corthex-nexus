# SCR-145 Stage workbench

[한국어](SCR-145.ko.md)

Path: `/p/{project}/{part}/{stage}`, with the optional query `?d={diagram}`. Flows: FL-001, FL-002, FL-003, FL-004, FL-005, FL-006, FL-007, FL-008, FL-012, FL-013.

Purpose: The owner reads a stage's diagram or item table and works on it: moves, comments, answers AI proposals, renames and connects, and confirms; on stage 01 during a workshop, edits sticky notes (SPEC-003 to SPEC-035, SPEC-038, SPEC-039).

Reopen remains available on an automatically resolved conversation.

## Item 240: delayed sending

On PC and phone, a proposal decision or question reply displays “Sends in 10 seconds” and Undo. Undo before sending cancels it; after 10 seconds the page sends the existing API request. Leaving the screen or closing the tab starts the send immediately, including on pagehide. The browser keeps the queued action, including any reply text, in local storage until the server confirms success. On a later visit the page warns about a decision or reply whose send could not be confirmed; a retry uses the same request key. If local storage is unavailable the page refuses to queue the action. Confirmation keeps its result preview and a separate confirmation question. Direct editing remains PC-only, and the confirmation blocks in SPEC-029 do not change.

On a PC the selected element has an “Edit name” button beside its name field, so saving a correction does not require a keyboard shortcut.

On a PC, choosing the next changed element in the tour focuses and selects its name field so that the owner can type and use the visible save button immediately.
