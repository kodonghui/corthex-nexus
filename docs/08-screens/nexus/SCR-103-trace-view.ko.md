# SCR-103 추적 화면

[English](SCR-103-trace-view.md)

목적: 사용자는 한 항목이 모든 단계를 거쳐 어디서 왔고 어디로 이어지는지 보고, 그 사슬을 항목마다 따라갑니다. (FL-105)

경로 `/#p={project}&id={id}`. 허브 페이지(SCR-101)의 보기이고, 서버와 기기 양쪽에 있습니다. 볼 수 있는 사람: Cloudflare Access가 들여보낸 누구나, 또는 그 기기의 사용자. 1차에서 만들었고, NEXUS 0.2는 페이지에 없는 프로젝트의 알림을 더합니다(SPEC-122). [모든 화면](README.ko.md#모든-화면)의 규칙을 따릅니다.

## 자료

| 자료 | 출처 |
| --- | --- |
| 항목: 그 ID, 제목, 종류, 프로젝트, 단계, 정의한 곳, 상태, 구분, 우선순위, 그리고 화면이면 그 상태와 화면 정의 | 허브 페이지의 자료(API-101) |
| 그것이 오는 곳과 이어지는 곳을 단계마다, 사슬이 닿는 앞뒤 단계, 그것이 적는 같은 종류의 항목, 그 결정 | 허브 페이지의 자료(API-101) |
| 정의한 항목이 없는 ID를 언급한 곳 | 허브 페이지의 자료(API-101) |
| 프로젝트와 ID | 페이지 주소의 `#p=`와 `&id=` 뒤 |

## 동작

| 동작 | 결과 | 실패 |
| --- | --- | --- |
| 이어진 ID 고르기 | 그 항목의 추적 화면 | 정의한 항목이 없는 ID: SCR-103#error |
| 원본 속 항목의 자리나 화면의 정의 열기 | 스냅샷이 링크를 주면 그 링크 | 없음: 링크가 없으면 자리를 글로 보임 |
| 닫기, Escape, 브라우저의 뒤로 단추 | 허브 페이지 SCR-101 | 없음 |

## 상태

| 상태 | 사용자가 보는 것과 할 수 있는 것 | 이어지는 응답 |
| --- | --- | --- |
| SCR-103#normal | 제목으로 ID와 그 제목이 포커스를 받고, 항목의 사실들, 그 아래 단계마다 묶은 "앞 단계"와 "뒤 단계"의 이어진 항목, "앞쪽으로 이어진 항목"과 "뒤쪽으로 이어진 항목", "같은 종류", "결정". 화면이면 `#empty` 같은 그 상태와 화면 정의가 있는 곳도 보입니다. 이어진 것이 없는 항목은 거기 "없음"이라고 보입니다. 닫기 | 허브 페이지의 자료(API-101#200) |
| SCR-103#error | 정의한 항목이 없는 ID: "{id}의 정의를 읽은 원본에서 찾지 못했습니다."와 "함께 언급한 항목", 그리고 그것을 언급한 곳들. 페이지에 없는 프로젝트를 가리키는 주소: 1차는 아무것도 보이지 않던 자리에 "이 프로젝트는 이 페이지에 없습니다."와 프로젝트 목록으로 가는 링크([고른 것 7](README.ko.md#이-단계가-고른-것)). 닫기 | 허브 페이지의 자료(API-101#200) |

해당하지 않는 것:

- 읽는 중과 권한: 보기는 요청 없이 페이지가 담은 자료를 읽고, 페이지를 연 사람에게 보입니다.
- 비어 있음: 항목은 언제나 자기 자신을 보이고, 이어진 것이 없는 항목은 SCR-103#normal에서 "없음"을 보입니다.
- 오래됨: 자기 상태가 없습니다. 보기는 허브 페이지의 자료에서 나오고, 그 시각은 SCR-101#stale이 보입니다.

## 경우의 수

| 종류 | 사용자가 보는 것 |
| --- | --- |
| 접근 | 이 보기에 닿지 않습니다: 허브 페이지의 접근을 따릅니다(SCR-101) |
| 입력 | 이 보기에 닿지 않습니다: 어떤 꼴의 주소든 SCR-103#error나 그 항목을 엽니다 |
| 대상 | 정의한 항목이 없는 ID, 또는 페이지에 없는 프로젝트: SCR-103#error |
| 상태 변화 | 이 보기에 닿지 않습니다: 페이지가 열린 동안 페이지의 자료는 바뀌지 않습니다 |
| 되풀이 | 같은 ID를 다시 고르면 같은 보기를 보입니다 |
| 동시성 | 이 보기에 닿지 않습니다: 아무것도 쓰지 않습니다 |
| 상한 | 이어진 것은 모두 보입니다. 긴 목록은 줄을 바꾸고, 글자가 많은 ID는 페이지를 넓히지 않고 끊어집니다 |
| 바깥 서비스 | 없음: 보기는 아무것도 보내지 않습니다 |
| 자료 노출 | 허브 페이지가 이미 담은 것뿐입니다 |
| 빈 응답과 스트림 | 이어진 것이 없는 항목: SCR-103#normal의 "없음". 스트림은 없습니다 |
| 화면 상태 | 두 상태를 320과 1440픽셀에서, [와이어프레임](wireframes.html#scr-103)에 |
| AI 응답 | 없음: NEXUS는 AI 모델을 부르지 않습니다(REQ-121) |

## 배치

| 영역 | 320픽셀에서 | 1440픽셀에서 |
| --- | --- | --- |
| 항목 | 검색 칸 아래의 판: 제목과 닫기, 그 아래 사실들을 이름 위에 값으로 | 같은 판을 열의 너비로, 사실들은 이름 옆에 값으로 |
| 사슬 | "앞 단계" 다음에 "뒤 단계"를 위아래로, 저마다 단계마다 묶어서 | "앞 단계"와 "뒤 단계"를 나란히 |
