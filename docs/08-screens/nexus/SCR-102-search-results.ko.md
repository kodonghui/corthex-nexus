# SCR-102 검색 결과

[English](SCR-102-search-results.md)

목적: 사용자는 페이지에 있는 모든 프로젝트에서 ID나 제목의 낱말에 맞는 항목을 찾아 그중 하나를 엽니다. (FL-105)

경로 `/#q={words}`. 허브 페이지(SCR-101)의 보기이고, 서버와 기기 양쪽에 있습니다. 볼 수 있는 사람: Cloudflare Access가 들여보낸 누구나, 또는 그 기기의 사용자. 1차에서 만들었고 NEXUS 0.2는 그대로 둡니다(SPEC-122). [모든 화면](README.ko.md#모든-화면)의 규칙을 따릅니다.

## 자료

| 자료 | 출처 |
| --- | --- |
| 낱말에 맞는 항목: 저마다의 ID, 종류, 제목, 프로젝트, 단계 | 허브 페이지의 자료(API-101)를 페이지 안에서 찾음 |
| 찾은 낱말 | 페이지 주소의 `#q=` 뒤 |

## 동작

| 동작 | 결과 | 실패 |
| --- | --- | --- |
| 결과 고르기 | 그 항목의 추적 화면 SCR-103 | 없음: 결과는 페이지의 자료에서 나옴 |
| 다른 낱말로 찾기 | 그 낱말의 결과 | 빈 글은 결과를 닫음 |
| 닫기, Escape, 브라우저의 뒤로 단추 | 결과 없는 허브 페이지 SCR-101 | 없음 |

## 상태

| 상태 | 사용자가 보는 것과 할 수 있는 것 | 이어지는 응답 |
| --- | --- | --- |
| SCR-102#normal | 제목으로 "“{words}” 검색 결과 {n}개"가 포커스를 받고, 그 아래 맞는 항목마다 한 줄: 단추인 ID, 종류, 제목, 프로젝트와 단계. 닫기 | 허브 페이지의 자료(API-101#200) |
| SCR-102#empty | "“{words}”와 맞는 항목이 없습니다."와, 다른 낱말을 찾을 수 있게 열린 검색 칸. 닫기 | 허브 페이지의 자료(API-101#200) |

해당하지 않는 것:

- 읽는 중, 오류, 권한: 검색은 요청 없이 페이지가 담은 자료에서 페이지 안에서 돌고, 어떤 글이든 올바른 검색입니다.
- 오래됨: 자기 상태가 없습니다. 결과는 허브 페이지의 자료에서 나오고, 그 시각은 SCR-101#stale이 보입니다.

## 경우의 수

| 종류 | 사용자가 보는 것 |
| --- | --- |
| 접근 | 이 보기에 닿지 않습니다: 허브 페이지의 접근을 따릅니다(SCR-101) |
| 입력 | 어떤 글이든 검색입니다. 낱말은 제목에 글로만 보입니다 |
| 대상 | 이 보기에 닿지 않습니다: 결과는 모두 페이지 자료의 항목입니다 |
| 상태 변화 | 이 보기에 닿지 않습니다: 페이지가 열린 동안 페이지의 자료는 바뀌지 않습니다 |
| 되풀이 | 같은 검색은 같은 결과를 보입니다 |
| 동시성 | 이 보기에 닿지 않습니다: 아무것도 쓰지 않습니다 |
| 상한 | 맞는 항목은 페이지 자료의 차례대로 모두 보이고, 긴 제목은 줄을 바꿉니다 |
| 바깥 서비스 | 없음: 검색은 아무것도 보내지 않습니다 |
| 자료 노출 | 허브 페이지가 이미 담은 항목뿐입니다 |
| 빈 응답과 스트림 | 맞는 것이 없음: SCR-102#empty. 스트림은 없습니다 |
| 화면 상태 | 두 상태를 320과 1440픽셀에서, [와이어프레임](wireframes.html#scr-102)에 |
| AI 응답 | 없음: NEXUS는 AI 모델을 부르지 않습니다(REQ-121) |

## 배치

| 영역 | 320픽셀에서 | 1440픽셀에서 |
| --- | --- | --- |
| 결과 | 검색 칸 아래의 판: 위에 제목과 닫기, 그 아래 맞는 항목마다 두 줄로, 위에 ID와 종류, 아래에 제목, 프로젝트, 단계 | 같은 판을 1,200픽셀 열의 너비로, 맞는 항목마다 한 줄로 |
