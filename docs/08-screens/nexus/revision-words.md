# NEXUS: the design revision's words

[한국어](revision-words.ko.md)

The words that the design revision of 2026-11-11 plans for SCR-110 to SCR-115 and SCR-130, in English and Korean. Its checkpoint has not passed ([the review's map](../../reviews/2026-11-11-design-review.md)), and none of these words is built. A word between `·` marks is a label of its own, and the English and the Korean of each row hold as many labels, with the same names in braces. In Korean the agent is AI ([choice 17](README.md#choices-this-stage-made)), and a push is 올리다, as the built labels of the first page say it, where the glossary's prose says 보내기. For the codes and states that the screens already have, they keep stage 08's [messages](README.md#messages) and [the redesign's words](redesign-words.md). This table has a fifth column, the row's status, so `nexus/tools/messages.mjs`, which turns tables of four columns into the views' words, does not read it; a task that builds a row moves it into [redesign-words.md](redesign-words.md) in the same change, without its status ([Words the design revision plans](README.md#words-the-design-revision-plans)). `open (D17)` marks what follows the recommendation of stage 02's decision D17, which is open. When this file and its Korean translation differ, the English file is the source.
