# SCR-146 확정 뒤 바뀐 곳

[English](SCR-146.md)

주소: `/p/{project}/{part}/{stage}/changes`. 흐름: FL-002, FL-004, FL-006.

목적: 사용자가 지난 확정 버전 뒤 더하고 빼고 바뀐 요소를 모두 보고, 반영을 기다리는 직접 편집을 취소하고, 확정합니다(SPEC-023, SPEC-029, SPEC-034).

## 데이터

| 데이터 | 출처 |
| --- | --- |
| 헤더: "내 차례 N", 할 일 수 | API-263 |
| 헤더: 프로젝트 메뉴 | API-262 |
| 지난 확정 버전 뒤 바뀐 곳(전후), 반영을 기다리는 직접 편집 | API-265 |

## 동작

| 동작 | 오퍼레이션 | 결과 | 실패 |
| --- | --- | --- | --- |
| 직접 편집 취소 | API-273 | 목록에서 빠지고 요소가 예전 모습으로 보임 | 이미 반영됨 → stale |
| 그림 확정 | API-275 | SCR-145의 confirmed 상태로 돌아감 | 반영 대기 변경 → waiting 상태. 문서가 바뀜 → stale |
| 그림으로 돌아가기 | - | SCR-145가 열림 | 없음 |

## 상태

| 상태 | 사용자가 보고 할 수 있는 것 | 응답 |
| --- | --- | --- |
| SCR-146#normal | 바뀐 요소마다 한 줄: 더함·뺌·바뀜과 전후. 반영 대기 직접 편집은 맨 위(각각 편집 취소). 끝에 확정 버튼. 목업에서: 작업 패널의 "확정한 뒤 바뀐 곳" 목록 전체. 휴대폰에서: 목록은 읽기만. 편집 취소와 확정은 "PC에서 하세요" 안내와 함께 보이지 않음. | API-262#200, API-263#200, API-265#200, API-273#200, API-275#201, API-275#200 |
| SCR-146#loading | 목록 자리에 회색 줄. 확정 버튼은 꺼짐. | - |

| SCR-146#error | 404: 그림이나 변경이 없음, 프로젝트 링크나 새로 고침. 그 밖: 메시지와 다시 시도. | API-262#default, API-263#default, API-265#404, API-265#default, API-273#400, API-273#404, API-273#409, API-273#413, API-273#415, API-273#default, API-275#400, API-275#404, API-275#409, API-275#413, API-275#415, API-275#default |
| SCR-146#permission | 401: 게이트로 갔다가 여기로. 403: 소유자가 아니라는 메시지만. cross-site: 새로 고침. | API-262#401, API-262#403, API-263#401, API-263#403, API-265#401, API-265#403, API-273#401, API-273#403, API-275#401, API-275#403 |

| SCR-146#waiting | 기다리는 편집이 있으면 확정 버튼이 꺼지고 "반영을 기다리는 변경을 먼저 반영하거나 취소하세요". | API-275#409 |
