# SCR-146 확정 뒤 바뀐 곳

[English](SCR-146.md)

주소: `/p/{project}/{part}/{stage}/changes`, 선택 쿼리 `?d={diagram}`. 흐름: FL-002, FL-004, FL-006.

목적: 사용자가 지난 확정 버전 뒤 더하고 빼고 바뀐 요소를 모두 보고, 반영을 기다리는 직접 편집을 취소하고, 확정합니다(SPEC-023, SPEC-029, SPEC-034).

## 데이터

| 데이터 | 출처 |
| --- | --- |
| 헤더: "내 차례 N", 할 일 수 | API-263 |
| 헤더: 프로젝트 메뉴 | API-262 |
| 지난 확정 버전 뒤 바뀐 곳: 더하고 빼고 바뀐 요소(지금 그림의 이름으로)와 확정한 커밋, 반영을 기다리는 직접 편집 | API-265 |
| 확정한 버전으로 가는 링크를 위한 프로젝트 저장소 | API-264 |

## 동작

| 동작 | 오퍼레이션 | 결과 | 실패 |
| --- | --- | --- | --- |
| 직접 편집 취소 | API-273 | 목록에서 빠지고 요소가 예전 모습으로 보임 | 이미 반영됨 → stale |
| 그림 확정 | API-275 | confirmed 상태, 그림으로 돌아가는 링크와 함께 | 반영 대기 변경 → waiting 상태. 문서가 바뀜 → stale. 그려지지 않음 → not-drawn 상태 |
| 그림으로 돌아가기 | - | SCR-145가 열림 | 없음 |

## 상태

| 상태 | 사용자가 보고 할 수 있는 것 | 응답 |
| --- | --- | --- |
| SCR-146#normal | 바뀐 요소마다 한 줄: 태그(더함, 뺌, 바뀜)와 지금 그림의 이름, 뺀 요소는 키. 목록 위에 "전"으로, 저장소에서 확정한 버전의 문서로 가는 링크(SPEC-034). 끝에 확정할 수 있으면 질문에 답하고 변경을 확인한 뒤 AI에게 기록을 요청한다는 설명과 확정 버튼. 목업에서: 작업 패널의 "확정한 뒤 바뀐 곳" 목록 전체. 지운 그림이면 바뀐 곳만 보이고 확정 버튼은 없음(SPEC-027). 휴대폰에서: 목록은 읽기만. 편집 취소와 확정은 "PC에서 하세요" 안내와 함께 보이지 않음. | API-262#200, API-263#200, API-264#200, API-265#200, API-273#200 |
| SCR-146#loading | 목록 자리에 회색 줄. 확정 버튼은 꺼짐. | - |
| SCR-146#empty | 확정한 적 없음: "아직 확정하지 않아 비교할 버전이 없어요." 바뀐 것 없음: "확정한 뒤 바뀐 곳이 없어요."(SPEC-034) | API-265#200 |
| SCR-146#error | 404: 확정이었으면 먼저 그림을 다시 읽어, 목록에 남은 지운 그림이면 바뀐 곳만 보이고 확정 버튼은 없음(SPEC-027). 아니면 그림이나 변경이 없음, 프로젝트 링크나 새로 고침. 그 밖: 메시지와 다시 시도. | API-262#default, API-263#default, API-264#404, API-264#default, API-265#404, API-265#default, API-273#400, API-273#404, API-273#409 (request-key-reused), API-273#413, API-273#415, API-273#default, API-275#400, API-275#404, API-275#409 (request-key-reused), API-275#413, API-275#415, API-275#default |
| SCR-146#permission | 401: 게이트로 갔다가 여기로. 403: 소유자가 아니라는 메시지만. cross-site: 새로 고침. | API-262#401, API-262#403, API-263#401, API-263#403, API-264#401, API-264#403, API-265#401, API-265#403, API-273#401, API-273#403, API-275#401, API-275#403 |
| SCR-146#stale | "문서가 바뀌었어요. 새 버전을 보세요."와 새로 고침. | API-273#409 (change-set-state), API-275#409 (document-changed) |
| SCR-146#waiting | 반영을 기다리는 변경 세트 모두: 맨 위에, 직접 편집은 각각 편집 취소와 함께(휴대폰에서는 없이), 수락한 AI 제안은 편집 취소 없이. 확정 버튼은 꺼지고 "반영을 기다리는 변경을 먼저 반영하거나 취소하세요". | API-275#409 (waiting-reflection) |
| SCR-146#not-drawn | 문서가 그려지지 않음: 확정 버튼이 꺼지고 "문서를 고쳐 그려지게 한 뒤 확정하세요."와 실패한 곳이 보이는 그림 링크. PC에서 확정할 때만 옴. | API-275#409 (not-drawn) |
| SCR-146#confirmed | 빈 목록 위에 "이 그림을 확정했어요. 이 단계의 모든 그림과 표가 기록되면 단계가 통과돼요."와 그림으로 돌아가는 링크. PC에서 확정할 때만 옴. | API-275#201, API-275#200 |
