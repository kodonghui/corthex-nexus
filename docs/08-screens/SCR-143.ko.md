# SCR-143 프로젝트 목록

[English](SCR-143.md)

주소: `/p`. 흐름: FL-001, FL-002, FL-009, FL-010.

목적: 사용자가 모든 프로젝트 공간을 진행 정도와 함께 보고 열며, 에이전트 자격을 발급하고 폐기합니다(SPEC-049, SPEC-050).

## 데이터

| 데이터 | 출처 |
| --- | --- |
| 헤더: "내 차례 N", 할 일 수 | API-263 |
| 헤더: 프로젝트 메뉴 | API-262 |
| 프로젝트 공간: 제목, 마지막 리비전과 보낸 때, 13단계 중 통과한 수, 할 일 수 | API-262 |
| 에이전트 자격: 이름, 발급한 때, 마지막으로 쓴 때, 폐기 | API-279 |

## 동작

| 동작 | 오퍼레이션 | 결과 | 실패 |
| --- | --- | --- | --- |
| 프로젝트 열기 | - | SCR-144가 열림 | 그새 사라짐 → SCR-144가 없다고 보여 줌 |
| 이름을 주고 자격 발급 | API-280 | 비밀값이 한 번 보이고, 복사 버튼과 설정할 hub 명령이 함께 나옴(secret 상태) | 비었거나 64자 넘음, 쓰는 이름 → 이름 옆 메시지, 입력 유지 |
| 자격 폐기 | API-281 | 한 번 물은 뒤 줄에 "폐기됨"과 시각. 다음 요청은 거절됨 | 그새 사라짐 → "NEXUS에 없어요"와 목록 다시 읽기 |

## 상태

| 상태 | 사용자가 보고 할 수 있는 것 | 응답 |
| --- | --- | --- |
| SCR-143#normal | 프로젝트를 줄로, 최근에 보낸 것부터. 줄마다 "13단계 중 N 통과"와 할 일 수. 줄을 누르면 단계별 상태와 도구 링크가 있는 SCR-144가 열림. 그 아래 자격 표(줄마다 폐기 버튼)와 발급 양식. SCR-144에서 지운 뒤에는 맨 위에 "demo를 지웠어요"가 한 번 나옴. 휴대폰에서: 프로젝트와 자격은 읽기만. 발급과 폐기는 "PC에서 하세요" 안내와 함께 보이지 않음. | API-262#200, API-263#200, API-279#200, API-280#200, API-281#200 |
| SCR-143#loading | 프로젝트와 자격 자리에 회색 줄. 발급 양식은 꺼짐. | - |
| SCR-143#empty | 프로젝트 없음: "에이전트가 처음 보내면 여기에 나와요. 아래에서 자격을 발급해 hub에 설정하고 --first로 보내세요." 자격 없음: "아직 보낼 수 있는 에이전트가 없어요." | API-262#200, API-279#200 |
| SCR-143#error | 읽기 실패: 표마다 메시지와 다시 시도(다른 표는 그대로 보임). 발급 거절: 이름 칸 옆 메시지, 이름 유지. | API-262#default, API-263#default, API-279#default, API-280#400, API-280#409, API-280#413, API-280#415, API-280#default, API-281#400, API-281#404, API-281#409, API-281#413, API-281#415, API-281#default |
| SCR-143#permission | 401: 게이트로 갔다가 여기로. 403: 소유자가 아니라는 메시지만. cross-site: 새로 고침. | API-262#401, API-262#403, API-263#401, API-263#403, API-279#401, API-279#403, API-280#401, API-280#403, API-281#401, API-281#403 |
| SCR-143#stale | "10:42에 읽음". 탭이 다시 보이면 다시 읽음. | - |
| SCR-143#secret | 새 자격의 비밀값을 상자에 복사 버튼과 함께, "지금만 보여요", `corthex-hub` 설정 안내. 페이지를 떠나거나 새로 고치면 다시 보이지 않음(SPEC-049). 발급은 PC에서 하므로 휴대폰에는 나오지 않음. 360픽셀 프레임은 좁은 PC 창. | API-280#201 |

## 경우의 종류

| 종류 | 화면이 보여 주는 것 |
| --- | --- |
| Access | permission 상태 |
| Input | 이름 칸 옆 메시지, 이름 유지 |
| Repeats | 발급과 폐기는 도는 동안 꺼짐. 같은 발급을 다시 보내면 비밀값 없이 같은 자격 |
| Data exposure | 비밀값은 한 번만 보이고 다시 읽지 않음 |
| Screen states | 모든 상태를 360·1440픽셀로 |
