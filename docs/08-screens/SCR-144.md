# SCR-144 Project

[한국어](SCR-144.ko.md)

Path: `/p/{project}`. Flows: FL-002, FL-006, FL-010, FL-013.

Purpose: The owner sees one project's 13 stages with their state and last checkpoint, links Notion and Jira, and deletes the space at #data (SPEC-013, SPEC-035, SPEC-046, SPEC-047).

## Data

| Data | Source |
| --- | --- |
| Header: "My turn N", the number of to-do entries | API-263 |
| Header: the project menu | API-262 |
| Stages: state, date of the last checkpoint, "changed since the pass" | API-264 |
| Tool links of the project and its stages, with the status last read and its time | API-264 |
| What deleting the space removes, with counts (#data) | API-277 |

## Actions

| Action | Operation | Result | Failure |
| --- | --- | --- | --- |
| Open a stage | - | SCR-145 opens | Nothing sent for it → SCR-145's empty state |
| Link a Notion page or a Jira project to the project or a stage | API-282 | The link shows with "not read yet" until NEXUS reads it | Not a Notion or Jira address → the message by the address, kept; the same link → no second link |
| Remove a tool link | API-283 | The link is gone | Already removed → the same result |
| Delete the project space | API-277, API-278 | After the owner types the project's name and confirms, the space is removed and the projects list opens with "Deleted demo" | Gone already → the projects list; the owner does not confirm → nothing removed |

## Kinds of cases

| Kind | What the screen shows |
| --- | --- |
| Access | permission state |
| Input | the address's message by the field, kept |
| Target | 404: the project is gone, with a link to the projects |
| Repeats | delete is off while it runs; a link added twice is one link |
| Outside services | a tool that cannot be read keeps its last status and time (SPEC-046) |
| Screen states | every state at 360 and 1440 pixels |
