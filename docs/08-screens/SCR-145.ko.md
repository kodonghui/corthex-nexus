# SCR-145 단계 작업대

[English](SCR-145.md)

주소: `/p/{project}/{part}/{stage}`, 선택 쿼리 `?d={diagram}`. 흐름: FL-001, FL-002, FL-003, FL-004, FL-005, FL-006, FL-007, FL-008, FL-012, FL-013.

목적: 사용자가 단계의 그림이나 항목 표를 읽고 작업합니다. 옮기고, 댓글 달고, AI 제안에 답하고, 이름 바꾸고 잇고, 확정합니다. 워크숍 중인 01단계에서는 스티커를 고칩니다(SPEC-003~035, SPEC-038, SPEC-039).

| --- | --- |
| Access | permission 상태 |
