# SCR-141 격리된 목업 미리보기

[English](SCR-141.md)

상태: 설계 정의입니다. 구현 또는 사용자 검토 통과를 의미하지 않습니다.

목적: 사용자가 원본 정보를 유지하며 자격 증명이 없는 격리된 미리보기에서 커밋된 HTML을 봅니다.

경로: `/p/:projectId/preview/:artifactId`

추적: FL-130, FL-136; SPEC-301, SPEC-307, SPEC-308, SPEC-332, SPEC-333, SPEC-337

| getIsolatedPreview | API-231 |

## 동작

## 레이아웃과 접근성

320·390px에서는 단일 열과 단계 메뉴, 768px에서는 접을 수 있는 탐색, 1440px에서는 탐색·콘텐츠·상세 패널을 사용합니다. 페이지 가로 스크롤 없이 긴 제목과 한국어를 줄바꿈합니다. 그림은 자체 스크롤 영역과 키보드 목록을 함께 제공합니다. 긴 원본·코드는 별도 영역에서 스크롤합니다. 다이얼로그는 제목·포커스 제한·Escape·복귀 포커스를 갖습니다. 상태 알림은 aria-live, 입력 오류는 필드 설명을 사용합니다. 주요 동작은 44px 이상, 모든 대상은 24px 이상입니다. 모든 상태는 두 테마에서 유지합니다.

컨트롤은 default·hover·pressed·focus·disabled·loading·selected·error를 구분합니다. 로딩 중 중복 제출을 막고 재시도는 같은 멱등성 키를 유지합니다. 에이전트 결과가 대기 중이어도 별도 질문을 보낼 수 있습니다. 계정 전환·로그아웃 시 비공개 초안과 캐시를 제거하고 비밀값 입력은 실패 시 유지하지 않습니다.
