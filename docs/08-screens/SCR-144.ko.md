# SCR-144 프로젝트

[English](SCR-144.md)

주소: `/p/{project}`. 흐름: FL-002, FL-006, FL-010, FL-013.

목적: 사용자가 프로젝트 하나의 파트별 13단계를 상태·마지막 체크포인트와 함께 보고, Notion·Jira를 잇고, #data에서 공간을 지웁니다(SPEC-013, SPEC-035, SPEC-046, SPEC-047).

## 데이터

| 데이터 | 출처 |
| --- | --- |
| 해당 프로젝트의 질문·확인 할 일과 대상 링크 | API-263 |
| 헤더: "내 차례 N", 할 일 수 | API-263 |
| 헤더: 프로젝트 메뉴 | API-262 |
| 파트와 그 단계: 상태, 마지막 체크포인트 날짜, "통과 뒤 바뀜" | API-264 |
| 프로젝트와 단계의 도구 링크, 마지막으로 읽은 상태와 시각 | API-264 |
| 공간을 지우면 사라지는 것과 수(#data) | API-277 |

## 동작

| 동작 | 오퍼레이션 | 결과 | 실패 |
| --- | --- | --- | --- |
| 단계 열기 | - | 그 파트와 단계로 SCR-145가 열림 | 보낸 것이 없음 → SCR-145의 empty 상태 |
| 프로젝트나 단계에 Notion 페이지·Jira 프로젝트 잇기 | API-282 | NEXUS가 읽을 때까지 "아직 안 읽음"과 함께 링크가 보임 | Notion·Jira 주소가 아님 → 주소 옆 메시지, 입력 유지. 같은 링크 → 두 번째 링크 없음 |
| 도구 링크 지우기 | API-283 | 링크가 사라짐 | 이미 지움(404 tool-link-not-found) → 성공했을 때처럼 목록에서 링크가 사라짐 |
| 프로젝트 공간 지우기 | API-277, API-278 | 사용자가 프로젝트 이름을 적고 확인하면 공간이 지워지고, 프로젝트 목록이 "demo를 지웠어요"와 함께 열림 | 이미 없음 → error 상태: "NEXUS에 없는 프로젝트예요"와 프로젝트 목록 링크. 확인하지 않음 → 아무것도 지우지 않음 |

## 상태

| 상태 | 사용자가 보고 할 수 있는 것 | 응답 |
| --- | --- | --- |
| SCR-144#normal | 단계 앞에 이 프로젝트에서 답할 질문을 먼저, 이어서 확인할 내용을 표시하고 각각 대상 대화나 그림으로 엽니다. 할 일 읽기 실패는 별도로 알립니다. 각 파트의 단계는 ‘무엇을 만들지 정하기’(01~04), ‘어떻게 만들지 정하기’(05~09), ‘만들고 확인하기’(10~13)로 접어 보여 주고, 묶음을 열면 원래 13단계와 진행 상태를 볼 수 있습니다. 각 단계 링크는 쉬운 목적을 먼저 쓰고 기존 단계 이름은 괄호에 남깁니다. 파트별로 묶은 13단계(파트가 없는 프로젝트는 한 그룹)를 줄로, 상태 태그, 마지막 체크포인트 날짜, 링크와 함께. 확정이 풀린 통과 단계는 "통과 뒤 바뀜"(SPEC-035). 도구 링크는 상태와 읽은 시각, 또는 "아직 안 읽음". 휴대폰에서: 단계와 링크는 읽기만. 잇기, 링크 지우기, 삭제는 "PC에서 하세요" 안내와 함께 보이지 않음. | API-262#200, API-263#200, API-264#200, API-278#200, API-282#201, API-282#200, API-283#200, API-283#404 (tool-link-not-found) |
| SCR-144#loading | 단계 목록 자리에 파트마다 회색 줄 13개. #data의 수도 회색. | - |
| SCR-144#empty | 아직 그린 것이 없는 공간: 모든 단계가 "아직 보낸 것이 없어요". | API-264#200 |
| SCR-144#error | 404: "NEXUS에 없는 프로젝트예요"와 프로젝트 목록 링크. 그 밖: 메시지와 다시 시도. 거절된 링크: 주소 옆 메시지, 입력 유지. | API-262#default, API-263#default, API-264#404, API-264#default, API-277#404, API-277#default, API-278#400, API-278#404, API-278#409, API-278#413, API-278#415, API-278#default, API-282#400, API-282#404, API-282#409, API-282#413, API-282#415, API-282#default, API-283#400, API-283#404 (project-not-found), API-283#409, API-283#default |

| SCR-144#stale | "10:42에 읽음". 탭이 다시 보이면 다시 읽음. | - |
| SCR-144#delete | #data에서: 사라질 스냅숏·그림·댓글·확정·레이아웃 수, 프로젝트 이름 칸, 이름이 맞으면 켜지는 삭제 버튼. 지운 뒤에는 프로젝트 목록이 열림. 삭제는 PC에서 하므로 360픽셀 프레임은 좁은 PC 창. | API-277#200 |

## 경우의 종류

| 종류 | 화면이 보여 주는 것 |
| --- | --- |
| Access | permission 상태 |
| Input | 주소 칸 옆 메시지, 입력 유지 |
| Target | 404: 프로젝트가 없음, 프로젝트 목록 링크 |
| Repeats | 삭제는 도는 동안 꺼짐. 같은 링크 두 번은 링크 하나 |
| Outside services | 읽을 수 없는 도구는 마지막 상태와 시각을 유지(SPEC-046) |
| Screen states | 모든 상태를 360·1440픽셀로 |
