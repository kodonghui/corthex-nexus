[조합 목업](nexus-combination.html)은 선택한 부분과 확정 미리보기·추가 확인, 반응형 레이아웃을 보여 줍니다. 되돌리기 버튼은 결정을 전송하지 않고 10초 대기만 흉내 냅니다. 원래 후보의 다른 동작은 승인된 단계 원본을 대체하지 않습니다. 이전의 전체 상태 목업은 `design/mockup/legacy-states.html`에 남아 있으며, 이 조합의 모든 화면 상태는 아직 확인하지 않았습니다.

조합 목업의 정상 첫 화면을 로컬에서 1440·360픽셀로 렌더링했습니다. CORTHEX 페이지 검사는 두 너비 모두 오류·경고·정보 항목이 없었고 토큰 검사에서도 토큰 밖 색상이 없었습니다. 이 결과는 다른 화면과 상태를 다루지 않습니다.
