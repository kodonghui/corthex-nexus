[조합 목업](nexus-combination.html)은 선택한 부분과 확정 미리보기·추가 확인, 반응형 레이아웃을 합친 작업 초안입니다. 되돌리기 버튼은 상태를 보여 주며 실제 시간에 따른 전송은 구현하지 않습니다. 나머지 화면 상태와 시각 점검이 남아 있습니다. 원래 후보의 다른 동작은 승인된 단계 원본을 대체하지 않습니다. 공개하기 전에 자료의 공개 안전성, 토큰과 실제 렌더링을 점검해야 합니다. 방향을 선택했다는 사실이 이 점검의 통과를 뜻하지는 않습니다.

조합 초안의 정상 첫 화면을 로컬에서 1440·360픽셀로 렌더링했습니다. CORTHEX 페이지 검사는 두 너비 모두 오류·경고·정보 항목이 없었고 토큰 검사에서도 토큰 밖 색상이 없었습니다. 이 결과는 다른 화면과 상태를 다루지 않습니다.
