# 재설계 목업과 선택한 토큰

[English](README.md)

상태: 사용자님의 설계 계속 지시에 따라 A를 선택했고 선택한 토큰을 설계 기준으로 고정했습니다. 샘플 인터랙티브 목업이며 배포된 v2 서비스나 NEXUS 개별 검토 통과를 뜻하지 않습니다.

[자체 포함 HTML 열기](../../../design/rebuild/index.html) · [A·B 비교](../../../design/rebuild/candidates.html) · [시각 측정](visual-review.ko.md)

## 목적과 다섯 방향

노트북이나 휴대폰에서 한 사용자가 여러 비공개 프로젝트를 검토하고 단계의 그림을 이해하며 항목 대화와 정확한 콘텐츠 버전의 결정을 합니다. 기존 화면과 토큰은 참고 자료이며 이번 기준은 새로 선택했습니다.

| 방향 | 검토한 구조 | 결과 |
| --- | --- | --- |
| 제품의 실제 소재 | 계획 보드·버전 표시·문서 여백·그림 캔버스 | A: 고정 프로젝트·단계 탐색, 중앙 산출물과 항목 상세 |
| 감정 | 차분한 읽기와 분명한 결정 | 라이트 배경, 절제한 초록 선택 표시, 경쟁하는 장식 모션 없음 |
| 사용자 | 여러 프로젝트를 오가는 한 사용자 | 명시적인 프로젝트 선택과 단계 맥락 복원 |
| 흔한 답의 반대 | 전체 화면 채팅 대신 산출물 우선 | 대화가 선택한 산출물 옆에 유지됨 |
| 다른 형식 | 가로 단계 탐색을 갖춘 버전 검토 카탈로그 | B: 넓은 문서 영역과 버전 검토 패널 |

외부 제품의 캡처·로고·문구·고객 수치를 복사하지 않았습니다. 참고 자료는 08 와이어프레임과 원본 산출물이며 외부 유사도 목표는 적용하지 않습니다. 두 후보 레이아웃으로 11개 화면을 확인할 수 있고 A를 이후 확장과 개발 방향으로 선택했습니다. B는 삭제하지 않고 비교할 수 있게 유지합니다.

## 선택과 이전 결정의 대체

A는 넓은 화면에서 224px 단계 사이드바·가변 산출물·320px 항목 상세를 사용합니다. 1200px 아래에서는 상세가 산출물 다음에 오고 850px 아래에서는 이름이 있는 단계 선택이 사이드바를 대체합니다. B는 가로 13단계 탐색과 380px 검토 패널을 사용합니다. 여러 프로젝트를 전환할 때 가로 탐색 없이 현재 단계가 보이는 A를 선택했습니다. 두 후보 모두 키보드 항목 목록과 명시적인 버전 검토를 유지합니다.

사용자님은 일반 설계 선택을 포함해 설계 끝까지 진행하도록 승인하셨습니다. 정확한 원문과 비공개 대화 맥락은 기존 프로젝트 기록에 있고 [원본 승인 기록](../../decisions/rebuild-authorization.ko.md)이 범위를 정의합니다. AI는 그 범위에서 A를 선택했습니다. 이를 사용자님의 직접 선택으로 바꾸거나 NEXUS 통과를 만들지 않습니다. 기존에 고정한 토큰은 원래 디렉터리에 유지합니다. 새 라이트 기본 제품을 요구하신 취지에 따라 이번 재설계의 시각 방향은 새 기준으로 대체했습니다.

## 토큰과 재생성

선택한 토큰은 DTCG 2025.10을 사용합니다. 공유 글꼴·간격·반경·대상 크기·모션은 base에, 라이트·다크의 색상은 각 파일에서 토큰당 하나의 값으로 정의했고 resolver의 기본값은 라이트입니다. B의 색상은 별도로 유지합니다. 한국어 대체 글꼴이 있는 시스템 글꼴은 새 패키지나 CDN을 요구하지 않습니다. 정보 밀도가 높은 일반 UI는 14px, 섹션은 16px, 페이지 제목은 28px, 메타데이터는 12px이며 본문 줄 간격은 1.6입니다. 한국어는 keep-all·break-word를, URL·코드는 anywhere를 사용합니다.

[Base](../../../design/rebuild/base.tokens.json) · [라이트](../../../design/rebuild/theme/light.tokens.json) · [다크](../../../design/rebuild/theme/dark.tokens.json) · [Resolver](../../../design/rebuild/tokens.resolver.json)

`python design/rebuild/render.py`로 커밋한 자체 포함 HTML을 재생성하고 `python design/rebuild/render.py --check`로 일치 여부를 확인합니다. 템플릿과 08 상태 데이터가 목업의 토큰 이름·화면 ID·상태 선택을 생성합니다. 화면 정의를 바꾸면 재생성과 시각 검증을 다시 합니다. 레포 의존성은 추가하지 않았습니다.

## 동작과 경계

프로젝트 검색·전환, 13가지 산출물 보기, 항목 선택, 버전별 대화, 답변 대기, 잘못된 반영 완료 없는 제안 수락, 체크포인트 확인·철회·충돌, 첫 게시 동의, 수신·건너뜀 게시 상태, 자격 증명의 일회 표시·분실·폐기, 과거 버전, 샘플 가이드와 격리 HTML 미리보기를 제공합니다. 화면·상태 선택으로 91개 설계 상태를 열고 두 테마와 두 후보를 비교할 수 있습니다. 로딩은 일반 화면의 크기를 유지하며 데이터 영역을 가리고 동작을 비활성화합니다.

모든 데이터는 샘플로 표시합니다. 입력은 메모리에만 유지하고 테마만 저장합니다. 로그아웃하면 비공개 샘플 초안과 선택을 초기화합니다. 목업 컨트롤은 인증된 요청을 보내거나 실제 NEXUS 프로젝트에 행동하지 않습니다. 격리 미리보기는 상위 문서·세션에 접근하지 못하면서 내부 샘플 스크립트를 실행할 수 있습니다. 이 로컬 시연이 운영 CSP나 실제 API 구현을 증명하지는 않습니다.

현재 운영 NEXUS는 원본 기록과 도메인·ERD·사이트맵 그림을 게시합니다. 새 HTML을 커밋하고 모든 화면 정의와 이 단계 검토 요청에 연결했습니다. 기존 운영 뷰어 안에서 커밋한 임의 HTML이 실행된다고 주장하지 않습니다. 격리된 v2 미리보기는 명시적인 개발·QA 작업입니다. 운영 런타임은 유지합니다.

## 검증 범위

시각 보고서에 실제 렌더 너비·테마·상태, 대비 수치, 경고의 사유와 샘플 동작 결과를 기록했습니다. 실제 OIDC 설정·Git 검증·v2 저장·서비스 성능·제품 전체 접근성·운영 데이터 이전과 복구·12 브라우저 에이전트 QA는 후속 작업입니다.

미리보기 상위 화면은 `frame-src 'none'`를 적용하고 `srcdoc`만 사용합니다. 신뢰한 하위 정책과 불투명 `allow-scripts` 샌드박스는 내부 목업 동작을 허용하면서 네트워크·탐색 권한을 차단합니다. 로컬 브라우저 픽스처에서 상위 정책이 프레임 자체 탐색의 샘플 요청을 차단함을 확인했으며 실제 서버·다른 브라우저 격리는 12 검사로 남깁니다.
