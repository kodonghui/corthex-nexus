# 목업 시각 검토

[English](visual-review.md)

범위: 로컬 샘플 HTML의 실제 Chromium 렌더·동작 검사입니다. 실제 서비스·12 전체 QA 통과를 의미하지 않습니다.

## 측정

선택한 A의 91개 상태 × 4개 너비 × 2개 테마 = 728개와 B의 11개 기본 화면 × 4개 너비 × 2개 테마 = 88개, 총 816개를 Chromium 156.0.8078.79에서 렌더했습니다. 너비는 320·390·768·1440px이며 두 테마 모두 측정했습니다. page-check 결과 오류 0개·경고 174개, 페이지 스크립트 오류 0개·외부 네트워크 요청 0개입니다. 잘림·페이지 가로 스크롤·한국어 단어 분리·최소 대상·이름 없는 필드 오류가 없었습니다. 잘리지 않은 전체 검사 결과와 HTML 해시를 [측정 파일](qa/measurements.json)에 보관했습니다.

| 선택한 A의 색상 쌍 | 라이트 | 다크 |
| --- | --- | --- |
| 본문 / 배경 | 13.06:1 | 13.48:1 |
| 보조 텍스트 / 배경 | 6.18:1 | 8.76:1 |
| 보조 텍스트 / 선택 | 5.33:1 | 5.45:1 |
| 주요 버튼 텍스트 / 강조 | 6.45:1 | 10.07:1 |
| 컨트롤 경계 / 선택 | 3.13:1 | 3.20:1 |
| 포커스 / 배경 | 6.58:1 | 9.08:1 |
| 경고 / 배경 | 5.88:1 | 8.80:1 |

색상 토큰의 실제 RGB를 선형화한 대비입니다. 텍스트 최소 4.5:1과 필수 경계·포커스 최소 3:1을 충족하는 쌍을 사용합니다. 이 수치만으로 제품 전체 WCAG 적합성을 선언하지 않습니다.

## 경고 검토와 실제로 본 화면

170개 orphan 경고는 버튼 내부의 별도 이벤트 종류 메타데이터와 좁은 화면의 짧은 마지막 행입니다. 문구가 누락되거나 단어가 잘린 결과는 아니며 줄 간격·메타데이터 계층을 유지합니다. 나머지 4개 contrast-image 경고는 320px error·stale 상태의 선택 항목과 목업 검토 도구가 겹치는 경우입니다. 해당 선택 배경의 보조 텍스트 대비를 5.33:1·5.45:1로 별도 계산했고, 페이지를 스크롤해 전체 항목을 확인할 수 있습니다. 다이어그램은 자체 스크롤 영역과 키보드 목록을 함께 제공합니다.

직접 확인한 렌더는 A 작업 화면 1440px 라이트·320px 다크, A 체크포인트 320px 라이트, B 작업 화면 1440px 라이트입니다. 다른 너비·상태는 측정만 했습니다. 이미지는 모두 샘플 데이터이며 실제 운영 캡처가 아닙니다.

## 동작 검증

샘플 동작 assertion 71개를 통과했습니다. 프로젝트 검색·전환·맥락 복원, 선택 항목 대화, 질문 대기, 제안 수락과 반영 구분, 결정 본문·출처·PR 주소 검사와 항목별 대화 복원, 13단계 키보드 목록 일치·항목 포커스·과거 결정 링크·통과/철회 유지·선행 조건 차단·버전 충돌 복구·테마와 후보 전환의 입력 보존, 확인 후 샘플 통과·철회, 과거 버전 통과 충돌, 일회 자격 증명·분실·폐기, 저장소 주소 검사·첫 동의, CI 건너뜀 표시, 격리 iframe 내부 동작·상위 문서 접근 거부·프레임 자체 탐색의 네트워크 차단, 로딩 크기 유지·비활성화, 테마 저장, Enter·Escape·포커스 복귀, 로그아웃 초기화, 불투명 샌드박스의 저장소 거부 처리와 reduced-motion 렌더를 포함합니다. 렌더 동안 HTML이 바뀌지 않은 해시도 확인했습니다.

## 아직 측정하지 않은 것

실제 OIDC 로그인·세션 만료 제공자 상황·실제 v2 API 저장·서버 게시·P95·전체 스크린 리더 지원·운영 CSP 공격 예제 전체·운영 데이터 이전·승인된 쓰기 복구·녹화 기반 플래시 빈도는 측정하지 않았습니다. 자동 모션·영상·오디오는 없으며 음량 기준은 해당하지 않습니다. 실제 제품 QA는 WBS의 명시적인 완료 조건을 통해 별도로 실행합니다.
