# NEXUS v3: 읽기 전용 브라우저 사전 확인

[English](aside-readonly-2026-11-27.md)

2026-11-27 인증된 브라우저로 기존 v3 배포를 읽었다. 코디네이터가 보고한 배포 커밋은 `445f7cf`이며 브라우저에서 독립 확인한 값은 아니다. 이전 서버 수정 커밋은 `0a6b152`다. 화면 경로를 확인한 로컬 원본은 병합된 NEXUS 커밋 `7c6c594`이며 배포 커밋이라는 뜻은 아니다. 프로젝트·자격·제안·확정·백업·서비스는 변경하지 않았다. 사용자 세션의 읽기만 수행했으며 시험 프로젝트와 다른 페어와이즈 역할은 확인하지 못했다. 프로젝트 목록·사용자 할 일·자격 목록 조회는 각각 HTTP 200, 생성하지 않은 합성 프로젝트의 조회는 404였다. 이름·자격 값·내용은 이 문서에 적지 않는다.

아래 캡처는 1440 × 900과 360 × 900이다. 프로젝트 내용, 자격 행, 프로젝트 선택기와 실제 개수는 브라우저에서 숨긴 뒤 촬영했다. 남은 공통 화면만 보여 주므로 가린 데이터나 개별 흐름 전이의 증거로 볼 수 없다. 단계 캡처는 작업 화면 내용 전체를 가렸다. 해당 상태를 촬영하지 못한 케이스에는 캡처가 있다고 주장하지 않는다.

여덟 케이스는 모두 게이트에서 **not run**이다. 계획은 격리된 환경에서 적용되는 각 전이·역할·너비의 캡처와 데이터 확인을 요구한다. 위 실배포 읽기는 보조 자료일 뿐 계획된 로컬 임시 서버 검증을 대체하지 않는다. 브라우저 에이전트의 서술은 탐색 안내로만 사용하고 통과 판정에 쓰지 않았다. 다른 사용자, 만료된 로그인, 폐기된 자격과 네트워크 손실 조합은 확인하지 못했다. 선택 단계인 AI 탐색 테스트는 실행하지 않았다.
