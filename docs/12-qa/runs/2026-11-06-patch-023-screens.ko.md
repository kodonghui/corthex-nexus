# NEXUS 0.2.3 화면 패치 확인

[English](2026-11-06-patch-023-screens.md)

NEXUS 0.2.3은 지금 화면의 틀은 그대로 두고 읽히게 고칩니다. 메인테이너가 2026-11-06 KST에 이 패치와 그 출시, 허브 플러그인 변경을 승인했습니다. 그림 중심 재디자인은 따로 이어집니다.

## 바뀐 것

| 항목 | 바뀐 것 | 근거 |
| --- | --- | --- |
| 단계 기록 | `.corthex/stages/nexus.json`에 기록된 확인 지점이나 결정이 있는 단계만 적었습니다. 01–06과 10은 완료, 07–09·11·12는 진행 중이고 저마다 다음 행동이 있습니다. 근거가 없는 단계는 지어 적지 않았습니다. | 허브가 이 파일을 저장소 기록으로 읽습니다. |
| 항목 없는 DDD 컨텍스트 | 전체 그림에서 항목이 없는 컨텍스트가 더는 빈 경계의 기본 자리를 쓰지 않습니다. 그런 틀은 보드 아래 한 줄에 나란히 섭니다. | `view-layout.test.js`. 2026-11-06에 읽은 실제 보드 둘에서 CORTHEX의 memory 부분은 겹치는 틀 쌍이 10에서 0으로, NEXUS 자기 보드는 18에서 9로 줄었습니다. |

| 단계 현황의 점검 | 점검마다 그 메시지로 쓰고, 규칙과 다른 코드는 '자세히' 안에 둡니다. | `view-overview.test.js`. SCR-109 고침. 브라우저 걷기에서 찾음. |
| ERD의 지움 표시 | 그림 속 지운 표의 설명 줄이 페이지의 언어를 씁니다. | 브라우저 걷기. 걷기에서 찾음. |

| 말 | 새 말은 모두 08단계의 "0.2.3이 더한 말"에 있고, `nexus/ui/messages.js`는 그곳에서 만듭니다. | `fields.test.js`가 새 키마다 08단계에서 왔는지 봅니다. |

다시 빌드한 브라우저 코드는 `nexus/src/view-code`의 파일 446개 가운데 209개의 이름을 바꾸고 3개를 고칩니다. 빌드는 고정된 외부 esbuild 0.28.2를 쓰고 브라우저 패키지 판을 확인합니다. 바로 앞 커밋을 깨끗한 사본에서 다시 빌드해도 커밋된 파일과 달랐으므로, 이름이 바뀐 까닭은 빌드 환경입니다. 검토된 컴파일 WASM 조각이 든 Excalidraw 덩어리가 새 이름을 받았습니다. 같은 값 해시와 고정된 원본 해시를 확인한 뒤 `nexus/ui/vendor/public-constants.json`에 그 항목을 더했습니다.

## 브라우저 걷기

이 클라우드 세션의 Playwright와 Chromium 1243으로 걸었습니다. ego lite와 Aside는 이 세션이 닿지 않는 컴퓨터에 있어, 출시 뒤 운영을 걷습니다. 합성 자료는 보기 시험 자료에 컨텍스트 다섯, 어긋남 종류 넷, 점검 셋, 프로젝트의 먼저 묻기 목록을 더한 것입니다. 컨텍스트 가운데 하나는 줄이 있고, 둘은 항목이 없고, 하나는 외부 시스템만, 하나는 외부 시스템과 애그리거트가 있습니다. 이 보드에서 이전 배치는 항목 없는 틀 둘을 첫 컨텍스트 위 한 자리에 두어 겹치는 쌍이 셋이었습니다. 고친 배치에는 없고, 캡처에서 두 틀이 보드 아래 나란히 섭니다.

흐름은 허브 → 단계 칸 01 → 그림 01 → 휠과 Ctrl+휠 → 항목 CTX-001 → 그림 05 → Ctrl+휠 → 항목 TBL-002 → 단계 현황 05입니다. 영어와 한국어로, 1440×1000과 390×844에서, 밝은 테마와 어두운 테마로 걸었습니다.

| 단계 | 본 것 |
| --- | --- |
| 허브 | 점검이 접힘: "점검 (3) · 경고 2 · 참고 1" / "Checks (3) · 2 warnings · 1 note". 프로젝트의 먼저 묻기 목록이 "원문 deletions (repositories, data) · 결제"와 "이 프로젝트에서 먼저 묻지 않는 것: 배포"로 보임 |
| 그림 01, 휠 | 그냥 휠은 페이지를 300 px 움직였고 배율은 16% 그대로. 안내는 한 번 떴고 다음 휠에는 다시 뜨지 않음. Ctrl+휠은 배율을 16%에서 26%로 바꿨고 페이지는 제자리. Excalidraw가 배율 숫자를 숨기는 390 px에서는 그림이 바뀌고 페이지는 제자리 |
| 항목 CTX-001 | "목적: Take an order", 원본은 닫힌 '자세히' 안 |
| 그림 05 | Ctrl+휠이 ERD 그림을 바꿈. 페이지는 0 px 움직였고 페이지 배율은 1 그대로. 지운 표는 "TBL-004 · CTX-001 · 지움" |
| 항목 TBL-002 | "외래 키: order_id → orders (id). 가리키는 행을 지우면 이 행도 지워집니다."와 "Foreign keys: order_id → orders (id). Deleting the referenced row also deletes this row." 어긋남은 "01 보드는 이 용어를 CTX-001에 두고, 이 표는 CTX-002에 있습니다." |
| 단계 현황 05 | 까닭 넷이 문장으로, 그 가운데 "이 표에 맞는 01 용어가 없습니다."와 "No 05 table names this aggregate.". 점검은 그 메시지로, 규칙은 '자세히' 안 |

64단계가 모두 통과했고, 콘솔 오류와 가로 넘침은 없었습니다. 중간 실행 한 번에서는 Ctrl+휠에 페이지가 움직인 것처럼 보였습니다. Playwright가 요소 캡처를 찍으려고 그림을 화면 안으로 굴린 탓이었습니다. 휠 이벤트마다 기록한 탐침으로 이벤트가 취소되고 페이지가 제자리임을 확인했고, 그 뒤로는 화면 캡처를 썼습니다.

## 남은 것

- 줄이 없고 용어집 용어가 있는 컨텍스트는 그 용어를 외부 시스템보다 300 아래에 그립니다. 원본에서 다음 컨텍스트도 줄이 없으면 두 틀이 닿을 수 있습니다. 걷기 보드의 첫 판에서 보였습니다. 실제 보드 둘에는 그런 쌍이 없고, 재디자인에서 DDD 그림을 다시 그립니다.
- NEXUS 자기 보드의 틀 아홉 쌍은 여전히 겹칩니다. 사건이 같은 시간 줄을 나눠 쓰는 컨텍스트들이라 경계 틀이 엇갈립니다. 재디자인에서 다룹니다.
- 단계 현황은 점검마다 스캐너 메시지를 보여 주며, 그 메시지는 영어입니다. 허브에는 이 점검들의 한국어 문구가 있습니다.
- 진짜 자료로 본 운영 화면, 휴대폰 터치, ego lite나 Aside 걷기는 출시 뒤에 합니다.
