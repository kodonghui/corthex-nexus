# NEXUS v3 QA: 임시 릴리스 게이트

추천은 첫 그룹을 포함해 **no-go**다. 이는 QA 계획과 로컬 검증의 임시 판정이며 릴리스 커밋의 게이트는 아니다. [QA 초안 PR 166](https://github.com/kodonghui/corthex-nexus/pull/166)의 커밋 `5d7184b`에 있는 계획의 243개 케이스는 당시 pass 206, not run 36, blocked 1이었다. 이후 workflow 권한이 추가됐고 TC-221이 PR 167의 고정 커밋 `6145f53`에서 예비 통과했다. 그 PR이 병합 전이어서 TC-221은 미실행으로 두며 QA PR 166의 커밋 `b68c73e` 기준 현재 pass 206, not run 37, blocked 0이다. 다수의 pass는 이전 커밋의 증거이므로 릴리스 커밋에서 다시 확인해야 한다. waiver는 없다. 기록된 열린 S1·S2는 없으며 S3 발견 사항 BUG-002~005가 열려 있다. BUG-001은 PR 165에서 수정·병합됐고 QA 초안 커밋 `bc3a3d0`에 반영됐다.

## 차단 항목

게이트 케이스 8개 TC-225, TC-226, TC-227, TC-230, TC-231, TC-233, TC-234, TC-235는 필수 브라우저 흐름 검증이 남았다. 계획에 적힌 화살표·역할·너비별 스크린샷과 데이터 확인이 필요하다. 이 항목들은 첫 그룹도 막는다. 로컬 합성 화면 캡처는 일부 상태만 다루므로 이 케이스들을 끝내지 못한다. 격리된 로컬 환경에는 실제 휴대폰과 실제 Access 로그인·만료 경로가 없었으며 테스트 게이트는 그 결과를 입증하지 못한다.

나머지 게이트 11개 TC-037, TC-038, TC-097과 TC-205~212는 배포 또는 운영 환경에서의 시간이 필요하다. 계획대로 다른 차단 항목을 해소한 뒤 첫 그룹에만 go를 물을 수 있으며, 각 증거가 통과할 때까지 전체 릴리스는 보류한다. 이 보고서는 배포, 실제 저장소 최초 전송 또는 기존 서비스나 데이터 삭제를 승인하지 않는다.

## 알려진 위험

통과하지 못한 비게이트 케이스는 18개다. 각각의 후속 확인은 계획에 남아 있다.

- TC-198, TC-199: 목표 환경의 P95 성능 측정이 필요하다.
- TC-200, TC-201, TC-202: 브라우저 버전·디자인·접근성 범위가 미실행이다.
- TC-213: 실제 읽기 전용 외부 도구 상태는 배포 환경과 적절한 자격이 필요하다.
- TC-221: 고정 hub 예비 검증은 통과했지만 고정 PR이 병합 전이라 통과로 세지 않는다.
- TC-228, TC-229, TC-232, TC-236, TC-237: 해당 흐름 전체 검증이 미실행이다.
- TC-238~242: 화면 상태와 목업 전체 비교가 미실행이다. 일부 로컬 상태 증거는 실행 보고서에 있다.
- TC-243: 실제 휴대폰 읽기와 댓글 검증이 미실행이다.

공유 호스트에서 Node 레이아웃 성능 테스트가 제한 1,000ms보다 긴 1,158ms와 1,034ms로 두 번 실패했고 같은 전체 검사가 한 번 통과했다. 원인은 아직 확인하지 못했다. 이 결과로 목표 환경의 P95를 입증할 수는 없다.

제어된 게이트·API 거절·응답 손실 테스트는 로컬 증거이며 배포된 Access나 외부 제공자 경로의 증거가 아니다. 선택 단계인 AI 탐색 테스트는 실행하지 않았고 게이트 항목이 아니다. go/no-go 판단 전 정확한 릴리스 커밋에서 숫자, 버그 상태, 고정 테스트, 화면 증거와 열린 리뷰 스레드를 다시 확인한다.
