# NEXUS0.2.1 실제 네이티브 걷기

[English](native.md)

원래 네이티브 기준20개와 정확한 단계 기록 보충2개에 한정 통과 근거가 있고, 독립 검토는22통과·WBS8완료를 권고합니다. 최종 판정은 본 QA·WBS 원장에 따로 반영합니다. 설치된 실제 Codex의 명령·파일 편집과 실제 호스팅 PR은 비공개 합성 저장소 한 곳과 로컬 실제 Node/SQLite 서버, 통제된 시험 사용자 동작을 사용했습니다. 운영 쓰기나 실제 사람의 승인을 뜻하지 않습니다.

A/B 선조 커밋의 할 일 읽기 전 전송, 제안·받음·반영·병합과 원본 불변, 병합 없는 닫기·사라진 대상 복구, 서로 다른 실제 세션, 확인 지점 기록·철회·잘못 병합한 기록의 교정 PR까지 걸었습니다. 보충 PR8의 합성 병합 fafac67cf525143d31b1871257af56653e8eb4a6을 가져온 뒤 공식 허브9636을 실행했습니다. NEXUS03의2026-11-03은 명시된 가상 fixture 날짜이며,04단계 초안과 in_progress 기록이 같은 PR로 병합됐습니다. 앞선11/05 근거도 보존합니다.

삭제 전 열린 의견3개·반영 대기1개의 ID를 먼저 보여 주고 시험 사용자의 명시 확인을 기다렸습니다. 실제 삭제1회 뒤 프로젝트용12개 표의 해당 행은 모두0이며,13표 재개·무결성·외래키 검사에서 공통 이주 기록3행을 보존했습니다. Git 저장소·파일·호스팅 PR8개는 유지했습니다.

실행별 허용은 설치 Python3.13·시험 폴더·지정 로컬 포트·형식화한 GitHub 동작으로 좁혔습니다. 시험 소유 모델·peer 프로세스와 포트를 닫고 새로 생긴 guard·빈 소유 부모만 정리했습니다. 전역 설정에 임시 fixture 신뢰 항목이 관측됐지만 쓴 프로세스는 포착하지 못했습니다. 그 정확한 항목만 조건부 제거해 관측된 시험 전 설정 SHA로 복구하고 나머지 바이트를 보존했습니다. 불투명하게 확인한 인증 파일2개 해시·Python 바이트/ACL·무관한 memory 파일도 앞선 관측과 같습니다. 인증 파일 복사나 설치 호스트 플러그인 갱신은 하지 않았습니다.

실제 네이티브 실행 기기는 Windows이며 기존 여러 OS의 CI와 구분합니다. 공식 허브9개 스크립트와 제품 프로토콜24개 모듈의 원바이트 동일성 근거를 바뀐 UI·자산·패키지에 확대하지 않습니다. 최신 UI는 별도 근거를 사용합니다. 공개 JSON은 허용 필드만 투영하며 비공개 저장소 식별자·URL, 홈 경로, 프롬프트·이벤트, 실행 프로필과 인증 메타데이터는 비공개로 둡니다. 독립 검토 해시는32767bbd3f17fffd47e7e373bf8ca7764586c4d00f4f767bef082890f7103647이며 원래 중단·입력 guard 실패·근거 경로 교정도 비공개 원본에 보존합니다.
