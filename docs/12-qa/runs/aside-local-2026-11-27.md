# NEXUS v3: Aside walk on a disposable local server

[한국어](aside-local-2026-11-27.ko.md)

The browser walked a loopback-only disposable v3 server through an SSH loopback tunnel. The server code was merged NEXUS commit `7c6c594`, with hub `e6b46ac`; the synthetic repository started at `0b823c8de3818bda21dc7c12a1da72bd80c26bee` and its changed schema was committed as `b7100d451c5eba0ecb7538c7199908f3489529dd`. The store, projects and credentials were test-only. A local test gate signed owner, other-person and expired assertions in memory; a test-only loopback wrapper selected the role. The hub credential was also kept in memory. No real credential, data or production service was changed.

The store was freshly created and then seeded with test data. The seed uses the fixed time 2026-11-23 UTC; later actions used the server clock. The UI displays local dates, which can differ from UTC dates. The controlled TC-235 clock applied only to the separate backup job.

The browser was a desktop browser at 1440 × 900 and 360 × 900; `(pointer: coarse)` was false at both widths. Thus the 360 captures show a narrow PC window, not a touch phone. The agent's narrative was used only as a navigation aid; the observations below come from browser actions, screenshots and server responses. Synthetic credential ID and secret fields were replaced with `[redacted]` before the one-time-display screenshots. A complete set of [synthetic screenshots](evidence/aside-local-2026-11-27/) is retained; the links below select the relevant states.
