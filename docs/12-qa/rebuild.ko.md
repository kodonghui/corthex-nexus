응답 사례는 v2 HTTP 동작 36개와 활성 응답 282개를 테스트 ID로 연결합니다. API-226의 기존 403 사례 ID는 제거 상태로 기록합니다. API-234의 403은 소유자 전용 게시 시도 조회를 확인합니다. 실제 핸들러에서 숫자 상태와 각 동작의 기본 응답을 확인합니다. 오류 코드, 본문 또는 헤더, 저장 상태를 대조합니다. 검사 중 관찰한 응답에는 관찰 결과를 기록합니다. [응답 사례](rebuild/api-cases.json)

브라우저 역할과 복구 경로를 같은 후보에서 실행합니다. 브라우저, 화면 폭, 테마, 확인된 추적 ID와 데이터 결과를 적습니다. 최초 실패의 근거와 재검증한 후보 커밋을 남깁니다. 운영 데이터는 서버의 보호된 복사본에서 이전과 복구를 대조합니다.

배포 전에 전체 HTTP 응답·브라우저 플로우, 접근성, 스테이징 성능, 세 프로젝트 이전·복구, 목업 격리, 실제 Google 로그인, 게시 결과와 사용자 체크포인트를 확인합니다. [배포 조건](../../nexus/src/rebuild-operator.js)
