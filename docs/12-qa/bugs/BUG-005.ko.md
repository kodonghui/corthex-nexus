# BUG-005: 삭제 백업 안내에 관한 QA와 화면 정의의 불일치

연결: TC-212, TC-240, SCR-144#delete, SPEC-013, SPEC-052, PR 124의 백업 결정. 발견일은 2026-11-27이다. Linux, Node 24.22.3, 제품 커밋 `ef12b79`와 QA 작업 트리, 일회용 loopback 서버와 로컬 서명 테스트 게이트에서 확인했다.

원인 가설: TC-212와 넘겨받은 메모 9는 삭제된 프로젝트가 백업에 30일 남는다는 삭제 안내를 기대한다. SCR-144#delete와 SPEC-013은 미리보기와 삭제 확인을 명세하지만 그 안내는 명시하지 않으며, PR 124는 삭제 문구에 이를 적을 수 있다고 한다. 어느 해석을 수정할지 정하기 전에 승인된 화면 정의와 QA 기대를 조정해야 한다.

재현: 합성 프로젝트를 일회용 서버에 전송하고 1440·360px에서 삭제 미리보기를 연 다음 이름을 입력해 삭제한다. 미리보기와 성공 알림 어느 쪽에도 30일은 나오지 않았다. TC-212의 기대: 삭제된 프로젝트가 백업에 30일 남는다는 안내. 실제: 미리보기는 개수를 보이고 성공 알림은 삭제됐다고만 표시한다. 로컬 실행 보고서의 FL-010 스크린샷과 데이터 확인을 참고한다. 이는 로컬 관찰이며 TC-212의 배포 서버와 보존 기간 확인은 미실행이다. 회귀 수정은 아직 하지 않았다.

환경: Linux, Node 24.22.3, 임시 로컬 테스트 환경.

Trace ID: TC-212, TC-240, SCR-144#delete, SPEC-013
