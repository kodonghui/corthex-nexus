# BUG-003: 프로젝트 stale 테스트가 분 경계에서 실패

연결: TC-176, SCR-144#stale, SPEC-035. 발견일: 2026-11-27.

원인: 테스트가 페이지 조회 뒤에 기대 읽은 시각을 계산하므로 그 사이 분이 바뀔 수 있다.

재현: `fad0adf`의 `server/test/project-screen.test.js` stale 테스트에서 실제 시간에 따라 진행하는 임시 시계를 사용해 기대값 계산 시각만 첫 조회보다 1분 앞으로 옮기고 stale tick 전에 원래 시계로 돌린다. Linux Node 24.22.3에서 assertion은 실제 `09:30에 읽음`, 기대 `09:31에 읽음`으로 실패했다. 이는 제어된 테스트이며 실제 브라우저 검증이 아니다.

기대: 분 경계와 관계없이 기대 시각은 페이지 조회 시각이다. 실제: 페이지는 앞선 조회 시각을 표시하지만 assertion이 실패한다. 회귀 수정과 검증은 아직 하지 않았다.
