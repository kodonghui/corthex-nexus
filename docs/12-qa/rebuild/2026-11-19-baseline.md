## Server and operator evidence

The v2 Node suite passed 29 tests. Instrumented loopback HTTP observed 275 responses across all 36 operations and 169 of the 283 declared operation/response pairs. The remaining pairs and any unasserted observations require their own checks. [Response cases](api-cases.json)

The protected three-project import preserved 4,565 source items, 23 comments, 16 replies and seven checkpoints. Content, authorship, order and version references were reconciled. Replaying the import added no duplicates. In the rollback rehearsal, the recovery journal restored both acknowledged HTTP writes and preserved the imported records. SQLite integrity and foreign keys passed. An incomplete release report returned `keep`.

The real Google session was verified on the isolated development service. GitHub Actions delivered the reviewed main commit to the existing hub. A full v2 private-repository publication, screen-reader validation and authenticated staging latency remain open. The baseline does not meet the production release gates.
