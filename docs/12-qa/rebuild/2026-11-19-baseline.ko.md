## 서버·운영 검증

v2 Node 테스트 29개가 통과했습니다. 로컬 HTTP 검사에서 36개 동작의 응답 275건을 관찰했고, 선언된 동작·응답 조합 283개 중 169개가 관찰됐습니다. 나머지 응답과 관찰만 한 응답은 별도 검증이 필요합니다. [응답 사례](api-cases.json)

보호된 서버 복사본에서 세 프로젝트의 원본 항목 4,565개, 코멘트 23건, 답변 16건, 체크포인트 7건을 원본과 대조했습니다. 같은 백업을 다시 적용해도 중복이 없었습니다. 복구 리허설에서는 저장된 HTTP 쓰기 2건과 이전 기록을 모두 확인했습니다. SQLite 무결성과 외래 키 검사를 통과했습니다. 근거가 부족한 배포 검사에서는 기존 서비스를 유지한다는 `keep` 결과가 나왔습니다.

개발 주소에서 실제 Google 세션을 확인했습니다. GitHub Actions가 검토 대상 main 커밋을 기존 hub로 전송했습니다. 비공개 레포의 v2 게시, 화면 낭독기와 인증을 포함한 스테이징 성능 검증이 남았습니다. 첫 실행 결과는 운영 배포 조건을 충족하지 못했습니다.
