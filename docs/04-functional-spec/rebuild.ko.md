## 외부 AI 경계

NEXUS makes no direct model-provider call in this release, so a provider/model key, endpoint retention claim and provider-call telemetry table are not fabricated. The external agent receives only explicitly scoped project work, the question and selected source/version; it must not receive browser cookies, service credentials or another project's data. Server authorization, lease, item/version existence and idempotency checks precede every reply/proposal write. Provider/model usage and data consent belong to the separately configured agent, not an implicit NEXUS subscription. More questions append separate work records; they neither overwrite an in-flight response nor run a source mutation twice. Attachments, voice and image-to-model input are deferred.
