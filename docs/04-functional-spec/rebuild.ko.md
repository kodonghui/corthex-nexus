## 외부 AI 경계

첫 버전의 NEXUS는 모델 공급자를 직접 호출하지 않습니다. 공급자·모델 키·엔드포인트 보존 정책·호출 측정 테이블을 지어내지 않습니다. 외부 에이전트에는 범위가 제한된 프로젝트 작업·질문·선택한 소스와 버전만 전달하고 브라우저 쿠키·서비스 자격 증명·다른 프로젝트 데이터는 전달하지 않습니다. 서버는 답변·제안 쓰기 전에 권한·lease·항목과 버전·요청 키를 확인합니다. 공급자·모델 사용과 데이터 동의는 별도로 설정한 에이전트의 책임이며 NEXUS 구독으로 묵시적으로 허용하지 않습니다. 추가 질문은 별도 작업으로 추가하며 처리 중인 답변을 덮어쓰거나 소스 변경을 두 번 실행하지 않습니다. 첨부·음성·이미지의 모델 입력은 후속 범위입니다.
