# NEXUS v3: WBS

[한국어](wbs.ko.md)

Stage 10 splits the approved functional spec (04), API contract (06) and screen definitions (08) into tasks. Each task has its spec rows, the operations, tables and screens it touches, the tasks it depends on, one owner, a size and a done condition someone else can check. Numbers start at TASK-413, after v2's TASK-412.

Sizes: S is about half a day of one Claude worker, M a day and L two days. A Claude worker (Opus 5.5 at xhigh) takes development to the end; every pull request gets a Claude review and, just before merge, one Codex review. The maintainer's tasks are decisions.

## 3. Open questions
